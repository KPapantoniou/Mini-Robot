# Vibration-Actuated 2-DOF Microrobot

This repository contains the complete implementation of my Master's thesis:
**"Modeling, Simulation, and Autonomous Control of a Vibration-Actuated 2-DOF Microrobot."**

Includes:
-  Physics simulation of dynamic model
-  Embedded controller code for real hardware
-  Computer vision algorithm for autonomous navigation
-  CAD schematics of the physical platform
-  Thesis and presentation materials
